# Vectes — Market Data & MT4 Trading Journal

**Live site → [aristoclesofstgo.github.io/vectes](https://aristoclesofstgo.github.io/vectes/)**

Vectes is a web app that pairs a year of market data for 24 assets with a personal trading journal. Traders connect MetaTrader 4 through a lightweight Expert Advisor and every closed trade syncs automatically: win rate, profit factor, drawdown, a daily P&L calendar and each entry and exit plotted on real candles. Market charts, cross-asset analytics, portfolio backtests with PDF reports and a SQL data lab sit alongside. Built with React, Supabase and a daily data pipeline.

Try it without signing up: **Try demo** creates a 7-day account with sample trades.

This repository only hosts the published website (the `gh-pages` branch is rebuilt automatically every day with fresh market data). The source code is private.

Questions, bugs or access requests: [open an issue](https://github.com/AristoclesofStgo/vectes/issues).
